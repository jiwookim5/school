# department_full

`department_search`를 확장한 최종 버전. 부분검색, 멀티키워드, 제외키워드, 점수 추가, 메뉴 기능까지 포함.

## 다루는 내용
- **부분 일치 검색**: `String.contains()`로 이름/학번/전화번호 부분 검색. 숫자 한 자리 키워드는 학년에만 매치
- **멀티키워드 검색(AND)**: 한 줄에 여러 키워드를 공백으로 입력하면 모두 만족하는 학생만 검색 (`scan.nextLine()` + `split(" ")`)
- **제외키워드**: 키워드 앞에 `-`를 붙이면 해당 조건을 가진 학생을 제외 (예: `-3` → 3학년 제외)
- **점수 기능**: `Student`에 `score` 필드 추가, `inputScore()`로 입력, `matchesScore(start, end)`로 구간 검색 (`-`만 입력하면 열린 구간)
- **메뉴로 기능 연결**: `switch`문 기반 메인 메뉴 + 검색 서브메뉴로 모든 기능 통합
- OCP(확장에는 열려있고 변경에는 닫혀있음): 기존 `read`/`print` 코드를 건드리지 않고 `score` 관련 기능만 추가

## 파일
- `Student.java` — id, name, phone, year, score + read/print/inputScore/matches(단일,멀티)/matchesScore
- `Department.java` — 메인 메뉴(`run`) → 검색 서브메뉴(`searchMenu`)로 연결되는 전체 프로그램

## 실행
```
javac Student.java Department.java
java Department
```

## 메뉴 구조
```
(1) 전체 출력 (2) 점수입력 (3) 검색 (0) 종료
└─ (3) 검색 선택 시
   (1) 학번/이름 검색  (2) 통합검색(멀티키워드)  (3) 점수 검색  (0) 종료
```

## 검색 예시
| 입력 | 의미 |
|---|---|
| `김` | 이름/학번/전화번호에 "김" 포함된 학생 |
| `김 2` (멀티검색) | 이름에 "김" 포함 **그리고** 2학년인 학생 |
| `김 -3` (멀티검색) | 이름에 "김" 포함 **그리고** 3학년이 아닌 학생 |
| `70 90` (점수검색) | 70점 이상 90점 미만 |
| `90 -` (점수검색) | 90점 이상 전체 |
