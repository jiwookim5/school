# 전화번호 관리 (Phone Contact Management) — 기본

## 개요
연락처(Contact) 클래스와 전화번호부(Main) 클래스를 이용하여 연락처를 관리하는 기본 예제입니다.

## 구성
- **Contact.java** — 연락처 정보(이름, 전화번호) 저장 및 비교
- **Main.java** — 연락처 입력, 검색, 출력 기능

## 핵심 개념
1. **클래스의 메소드** — read(), print(), equals() 등
2. **ArrayList** — 동적 배열로 여러 연락처 저장
3. **검색** — 연락처 이름으로 검색하여 정보 출력

## 실행 방법
```bash
javac Contact.java Main.java
java Main
```

## 학습 포인트
- 클래스의 기본 구조와 메소드
- ArrayList를 이용한 동적 자료 관리
- 참조 변수와 메소드 호출
