# Scanner 연습 (Scanner Exercise)

## 개요
Scanner를 이용한 배열 입력, 반복 입력 등 다양한 연습 예제입니다.

## 구성
- **ScannerBasic.java** — Scanner 기본 사용법 복습
- **Scanner_array.java** — Scanner로 배열 데이터 입력받기
- **Scanner_loop.java** — Scanner를 이용한 반복 루프

## 핵심 개념
1. **배열에 Scanner 입력** — 반복문과 함께 사용하여 여러 값 입력
2. **조건부 반복** — 특정 입력값(예: 0)을 받으면 종료
3. **입력 검증** — 잘못된 형식의 입력 처리

## 실행 방법
각 파일별로:
```bash
javac ScannerBasic.java
java ScannerBasic
```

## 학습 포인트
- Scanner와 for 루프를 함께 사용하여 배열 채우기
- `while (true)` + 조건에 따른 `break`로 유연한 입력 제어
